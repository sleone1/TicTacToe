     checkWinner(Board) → Player (null = no winner)

     Wins (parameterized where it helps; each win type uses a mix of X and O so
     neither player is special-cased)

     2. Vertical: columns 0–3
     3. Diagonal: main diagonal (0,0)→(3,3) and anti-diagonal (0,3)→(3,0)
     4. Four corners
     5. 2x2 box: all 9 top-left positions (rows 0–2 × cols 0–2)

     No winner
     6. Empty board
     7. Full board with no win condition (the strongest negative case)
     8. Near misses, 3 of 4 cells, one per condition: row, column, diagonal,
     corners, box. These catch off-by-one loop bounds and "3 in a row wins"
     logic carried over from the 3x3 game.

     anyMovesLeft(Board) → boolean

     1. Empty board → true
     2. Full board except one empty cell at (3,3) → true. The last cell is the
        one most likely to be missed by an off-by-one loop.
     3. Full board → false

     isGameOver(Board) → boolean

     The individual win types are already covered by the checkWinner tests, so
     this only needs to check how the two inputs combine:
     1. No winner, moves left → false
     2. Winner, moves left → true
     3. Full board with no winner (draw) → true
